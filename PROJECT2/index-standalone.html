HOW IT WORKS

ENCRYPTION

Encryption transforms readable plaintext into unreadable ciphertext using a defined algorithm and a key.

DECRYPTION

Decryption reverses the transformation, recovering the plaintext when the correct key is supplied.

THE CAESAR CIPHER

Each letter moves a set number of positions through the alphabet, wrapping from Z back to A. Other characters stay unchanged.

Educational use only. The Caesar cipher is intended for educational purposes. It is not secure enough to protect real confidential information.
