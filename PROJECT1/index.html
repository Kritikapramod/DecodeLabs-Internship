      Why length and variety matter

      Length

      Every extra character multiplies the number of possible passwords, so longer passwords are generally much harder to guess.

      Variety

      Mixing uppercase letters, numbers and symbols enlarges the pool of characters an attacker must try for each position.

      Predictability

      Attackers try common passwords and patterns like abc, 123 or aaa first, so predictable choices are risky.

      This is an educational estimator, not a guarantee of security. Use a unique password per site and a password manager.
